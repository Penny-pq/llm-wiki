# Attention Is All You Need（Vaswani et al., 2017）

- 發布者：arXiv / NeurIPS 2017 論文
- 年份／查閱日期：2017
- 原始網址：https://arxiv.org/abs/1706.03762

## 摘要筆記
- 論文提出 Transformer 架構，核心是 attention mechanism。
- 作者提出不依賴傳統循環式或卷積式序列處理的架構，並在機器翻譯任務上進行實驗。
- 這篇論文是理解 Transformer 歷史與自注意力機制的重要一手研究來源。
## 可支持的簡報內容
Transformer 的提出背景、attention 作為核心機制。
## 使用提醒
論文原始實驗主要針對機器翻譯；不要把論文結果直接解讀成「所有現代 LLM 的完整設計」。
