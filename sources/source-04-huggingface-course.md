# LLM Course – Introduction（Hugging Face）

- 年份／查閱日期：線上教材；查閱日期 2026-11-24

## 摘要筆記
- LLM 是自然語言處理領域近年重要的發展方向。
- 教材以 Transformers、Datasets、Tokenizers 等工具介紹 LLM 生態系。
- 學習 LLM 不只需要理解模型本身，也需要認識資料處理、tokenization、模型使用與評估。
## 可支持的簡報內容
LLM 所處的 NLP 脈絡，以及模型、資料集、Tokenizer 等元件的關係。
## 使用提醒
此來源主要作為延伸學習入口，不用它單獨支持所有模型原理主張。
