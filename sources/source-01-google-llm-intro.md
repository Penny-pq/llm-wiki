# Introduction to Large Language Models（Google Machine Learning Crash Course）

- 發布者：Google for Developers
- 年份／查閱日期：線上教材；查閱日期 2026-11-24
- 原始網址：https://developers.google.com/machine-learning/crash-course/llm?hl=zh-TW

## 摘要筆記
- 語言模型會估算符記（token）序列出現的可能性；LLM 是參數規模很大、能利用較廣脈絡進行預測的語言模型。
- 模型表現與資料、參數、脈絡及架構有關，不能只用「資料越多就一定越好」概括。
- 教材介紹從 N-gram、循環神經網路到 Transformer 的脈絡，適合說明技術演進。
- LLM 的能力與限制都要介紹，不能把生成流暢等同於事實正確。
## 可支持的簡報內容
LLM 基本定義、token 序列預測、背景脈絡、入門概念。
## 使用提醒
這是教學教材的整理，不代表所有 LLM 都採用完全相同的訓練細節。
