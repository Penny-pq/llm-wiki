# 教學簡報大綱｜從零認識 LLM

## 教學對象
沒有人工智慧或程式設計背景的初學者。

## 學習目標
看完簡報後，讀者能夠：
1. 用自己的話說明 LLM 是什麼。
2. 解釋 Token、Tokenizer 與 Embedding 的差別。
3. 說明 Transformer／自注意力的基本概念。
4. 分辨預訓練、生成與微調。
5. 說出 LLM 的至少兩項限制及查證方法。

1. 封面：從零認識 LLM

10. 重點回顧與來源
