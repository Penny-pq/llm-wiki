# 大型語言模型是什麼？

## 1. 語言模型的基本概念
語言模型（Language Model）會根據已提供的文字脈絡，估計接下來可能出現的 token 或 token 序列。大型語言模型（Large Language Model, LLM）通常指具有大量參數、能從大量資料學習語言模式並處理較廣脈絡的模型。

## 2. 用生活例子理解
可以把語言模型想像成一個非常擅長根據上下文接續句子的系統。看到「今天下雨，我出門記得帶……」，模型會根據學到的語言模式，評估「雨傘」等詞接續的可能性。這個例子是概念比喻，不代表模型像人一樣理解世界。

## 3. LLM 能做什麼？
常見用途包括文字生成、摘要、翻譯、問答、改寫與程式碼輔助。實際表現會受模型、提示內容、上下文和任務影響。

## 4. 重要觀念
- LLM 不是資料庫：它不一定能逐字回憶訓練資料。
- 回答流暢不等於回答正確。
- 不同 LLM 的架構、訓練方式和能力不完全相同。
