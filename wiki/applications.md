# LLM 的應用、限制與負責任使用

## 1. 常見應用
- 學習輔助：整理概念、生成練習題、提供不同解釋方式。
- 文字工作：摘要、翻譯、改寫、草擬內容。
- 資訊處理：協助分類、抽取重點與問答。
- 程式輔助：解釋程式碼、提出除錯方向。

## 2. 幻覺（Hallucination）
幻覺指模型生成看似合理、流暢，但實際上不正確或沒有可靠依據的內容。語言模型的生成目標與事實查證並不完全相同，因此即使語句自然，也可能包含錯誤。

## 3. 其他限制
- 偏誤：模型可能反映訓練資料中的偏誤。
- 時效性：模型可能不知道最新資訊，除非有連接即時資料來源。
- 資料與隱私：使用者應避免輸入不必要的個人或機密資料。
- 成本與資源：訓練及推論都可能需要大量運算資源。

## 4. 使用建議
1. 把 LLM 當成協助思考與整理的工具，而非唯一權威。
2. 重要事實要回到可靠來源查證。
3. 對醫療、法律、財務等重大決策，不應只依賴模型回答。
4. 注意資料來源、日期與適用範圍。
