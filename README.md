# LLM Wiki 教學簡報專案

## 如何使用
1. 解壓縮整個資料夾。
2. 先閱讀 `AGENTS.md`，了解專案規則。
3. `sources/` 有 6 篇來源摘要與來源登錄。
4. `wiki/` 是整理後的知識庫。
5. 用瀏覽器直接開啟 `presentation/index.html` 即可瀏覽簡報。
6. `workflow.md` 說明 graph、loop、檢查點及待填寫反思。
7. 專案根目錄也有 `index.html`，方便 GitHub Pages 直接以首頁顯示簡報。

## 重要
- 目前提供的是可檢視與修改的初版專案，不代表已完成老師要求的「先討論、後生成」過程紀錄。
- 建議保留與 AI 討論規格、檢查 Wiki、檢查大綱及測試簡報的截圖，作為作業歷程證據。
- `workflow.md` 的反思欄位必須在你實際操作後填寫。
- 部署 GitHub Pages 前，確認 repository 的根目錄與 `presentation/index.html` 的路徑。若老師要求首頁網址直接開啟簡報，可將簡報複製到專案根目錄並命名為 `index.html`，或調整 Pages 發布資料夾。
