A beginner's guide

從零認識
大型語言模型

LLM 如何把文字轉成模型能處理的形式，又如何一步步生成回答？

先建立一個觀念：LLM 很擅長生成語言，但「說得流暢」不代表「內容一定正確」。

本簡報以本專案 LLM Wiki 為知識來源。

01｜基本概念

LLM 是什麼？

大型語言模型（Large Language Model, LLM）是一種從大量資料中學習語言模式，並根據上下文預測 token 序列的模型。

大量資料

讓模型接觸多樣的語言用法與資訊模式。

大量參數

參數是模型在訓練中調整的數值，用來表示學到的模式。

上下文

模型會利用前後文，判斷接下來較可能出現什麼。

想像句子：「下雨了，出門記得帶……」模型會根據上下文評估「雨傘」等接續內容的可能性。
02｜文字如何進入模型

Token、Tokenizer、Embedding

文字→Tokenizer→Token ID→Embedding
Token（詞元）

模型處理文字的基本單位，可能是字、詞、標點或子詞片段。

Tokenizer（分詞器）

依模型規則把文字切分並轉成 token 序列。

Embedding（嵌入）

把 token 轉成數值向量，作為模型運算的表示。

注意：一個單字不一定等於一個 token；不同模型可能使用不同 tokenizer。

03｜核心架構

Transformer：參考上下文

Transformer 是許多現代 LLM 使用的重要神經網路架構。它的核心機制之一是自注意力（Self-attention）。

自注意力讓模型在處理某個 token 時，也能參考序列中其他 token 的資訊，依相關程度整合上下文。
例子 A

「蘋果放在桌上」——蘋果指水果。

例子 B

「我用蘋果手機」——蘋果指品牌。

Encoder 與 Decoder 是 Transformer 常見元件，但不同模型可能採用不同組合；不是每個模型都有兩者。

04｜模型如何學習

預訓練：從大量例子學模式

預訓練（Pretraining）是先使用大量資料訓練模型，調整參數，讓模型逐漸學到語言中的規律。

訓練資料→模型預測→計算誤差→調整參數

對許多自回歸語言模型而言，常見訓練目標是根據前文預測下一個 token。不過，不同模型可能使用不同訓練目標。

訓練是建立模型能力的過程；一般使用者輸入問題後得到回答，則屬於推論／生成。
05｜模型如何回答

逐步生成文字

使用者送出提示後，模型根據目前上下文計算下一個 token 的可能性，選出或抽樣 token，再把它加入上下文，重複進行。

提示→預測 token→加入上下文→繼續預測
可以把它想成逐步接龍：每次產生一小段，再以目前內容為基礎繼續生成，直到符合停止條件。

這是概念簡化；實際結果也會受到解碼策略與系統設定影響。

06｜調整模型與使用方式

微調和提示詞有什麼不同？

提示詞設計

透過指令、背景與範例，引導模型產生較符合需求的輸出；通常不更新模型參數。

微調（Fine-tuning）

使用特定資料進一步訓練既有模型，調整參數，使它更適合特定任務。

蒸餾（Distillation）

利用較大型模型提供的輸出或知識訓練較小模型，在成本、速度與表現間取捨。

07｜能力與限制

為什麼不能完全相信 LLM？

幻覺

可能產生看似合理、實際卻錯誤或缺乏依據的內容。

偏誤

可能反映訓練資料中的偏見或不平衡。

時效性

模型不一定掌握最新資訊，需確認資料日期。

資源成本

訓練與推論都可能需要大量運算資源。

重要提醒：回答流暢不等於事實正確。重要資訊應回到可靠來源查證。
08｜負責任使用

使用 LLM 的四個好習慣

  • 把模型當成協助整理與思考的工具，而不是唯一權威。
  • 重要數據、日期、人物與研究結論要查原始來源。
  • 提供清楚的背景與限制，讓問題更具體。
  • 避免輸入不必要的個人資料或機密內容。
好的使用方式不是盲目相信 AI，而是善用它的效率，同時保留自己的判斷。
